- Sometimes stories will need a human in the loop
- In this event, items should go into a custom page called "Actions Items", at the route `/action-items`.
- Here the user can quickly respond to each item. User can enter a response and that will be sent to the supervisor along with a system prompt and the associated story.
- Must use list view (from DEV-40)
